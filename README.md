# Java Streams Interview Questions

This repository contains a collection of Java Streams interview questions, designed to help you prepare for technical interviews focusing on Java 8 and beyond.

## Questions

1.  **What are Java Streams, and how do they differ from Java Collections?**
2.  **Explain the difference between intermediate and terminal operations in Java Streams.**
3.  **How do you filter elements in a Java Stream?**
4.  **How do you transform elements in a Java Stream?**
5.  **How do you aggregate data in a Java Stream?**
6.  **How do you group elements in a Java Stream?**
7.  **How do you sort elements in a Java Stream?**
8.  **How do you handle null values in a Java Stream?**
9.  **How do you parallelize a Java Stream?**
10. **What are method references, and how are they used with Java Streams?**
11. **Explain the differences between `forEach()` and `peek()` operations.**
12. **How to flatten a stream of collections?**
13. **Explain the differences between `findFirst()`, `findAny()`, and `anyMatch()` operations.**
14. **Explain the `Collectors` class.**
15. **Explain the difference between filter and map.**
